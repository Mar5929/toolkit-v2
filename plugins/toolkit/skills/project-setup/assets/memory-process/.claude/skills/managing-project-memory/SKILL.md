# Managing project memory

Use this skill to keep project memory accurate and useful to a later session. A memory record holds one subject that no other project record holds. The project's Current State is the short page of what is true now. A session is one chat with the agent.

Open [references/memory-process.md](references/memory-process.md) whenever a turn might need a memory read, save, correction, or update to the project's Current State. It gives the rules for what to keep, what to file elsewhere, the owner's approval, and what to record before the turn ends. For every memory read or write, also open [references/memory-store.md](references/memory-store.md). Setup places only this project's local or Notion storage instructions at that path.

A work item and its project tasks belong to `managing-work-items`. A decision or question that several work items need, a source, a project term, or a fact about the system belongs to `filing-project-records`.
