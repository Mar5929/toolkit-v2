# Cite Recalled Knowledge

When an answer, a recommendation, or a decision uses something you recalled from project knowledge, say where it came from, so the owner can see what it is based on.

Project knowledge is `DECISIONS.md`, `system/`, `sources/`, `reference/`, work items, memory, Current State, and the rules in `.claude/rules/`.

- Name the source where you use it, by its ID when it has one, for example "(DEC-012)", "(`system/security-model.md`, SEC-04)", or "(WI-031, Q-04)".
- Put a short Sources list at the end of the reply, just above the closing question or the words that continue the work: one line per source, naming the file, record, or work item and what you took from it.
- Leave the list out when the reply used no recalled knowledge.
