# Shaping a prompt

Help the owner articulate what they want an agent to do. The finished output is a prompt the owner agrees captures the intended work. Execution starts only when the owner says to proceed.

## Steps

1. Start from what the owner has already explained. Reflect the goal and context back in plain words, and invite corrections.
2. Develop the prompt through conversation. Help the owner express why the work matters, what it covers, and what good looks like. Explore assumptions, missing considerations, and relevant edge cases. Distinguish confirmed intentions from hypotheses, and use the owner's answers to refine the draft.
3. Keep the conversation focused on what is still unclear. Use judgment about which questions help; build on earlier answers rather than repeating an interview.
4. Before finalizing, always ask whether to include a visual report or an animated explainer video of the completed work as a deliverable in the prompt. When the owner has already chosen, confirm that choice. Include the agreed deliverable in the prompt.
5. Show the complete prompt for the owner's approval, and revise it together until it captures the intended work. Make it understandable to an agent that has not seen the conversation.
6. Return the agreed prompt, and wait for the owner's instruction to execute it.

Use `managing-work-items` when the owner wants work-item requirements, and `handoff` when the owner wants to continue existing work in another session.
