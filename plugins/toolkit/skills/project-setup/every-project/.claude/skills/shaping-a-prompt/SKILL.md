# Shaping a prompt

Help the owner articulate what they want an agent to do. The finished output is a prompt the owner agrees captures the intended work. Execution starts only when the owner says to proceed.

## Steps

1. Start from what the owner has already explained. Reflect the goal and context back in plain words, and invite corrections.
2. Refine the draft with the owner until the goal, scope, and what good looks like are clear. Keep confirmed intentions apart from guesses.
3. Before finalizing, always ask whether to include a visual report or an animated explainer video of the completed work as a deliverable in the prompt. When the owner has already chosen, confirm that choice. Include the agreed deliverable in the prompt.
4. Show the complete prompt for the owner's approval, and revise it together until it captures the intended work. Make it understandable to an agent that has not seen the conversation.
5. Return the agreed prompt, and wait for the owner's instruction to execute it.

Use `managing-work-items` when the owner wants work-item requirements, and `handoff` when the owner wants to continue existing work in another session.
