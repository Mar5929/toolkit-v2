# Memory in local files

Follow these steps when the owner chooses to keep memory in local files. The job is done when `memory/` and the skill `managing-project-memory` are in the project, `PROJECT.md` records the choice, and the session-start command prints the project's Current State, which is the project's one short page of what is true now.

## Steps

Do steps 1 to 4 right after the answer, before the next interview question. Do steps 5 and 6 when setup finishes. This choice has no question beyond the one about the default, needs no sign-in, and makes nothing outside the project folder.

1. **Tell the owner how the toolkit sets up memory in local files by default, and ask whether that is what the owner wants.** [reference/local-memory-default.md](reference/local-memory-default.md) holds the default.
2. **Copy this choice's files into the project**: the skill `managing-project-memory`, which the other skills call for every memory step, the folder `memory/`, and the startup module and reminder text in `.claude/hooks/`. [reference/what-local-memory-adds-to-a-project.md](reference/what-local-memory-adds-to-a-project.md) lists them.
3. **Copy the shared record files into the project.** `choices/memory/repository-records/files-to-add/` holds `DECISIONS.md` and `wiki/product-wiki/`. [what-repository-records-add-to-a-project.md](../repository-records/reference/what-repository-records-add-to-a-project.md) lists what it adds.
4. **Write the choice's lines in `PROJECT.md`, `AGENTS.md`, `.gitignore`, and `.ignore`.** [reference/what-local-memory-adds-to-a-project.md](reference/what-local-memory-adds-to-a-project.md) and [what-repository-records-add-to-a-project.md](../repository-records/reference/what-repository-records-add-to-a-project.md) give each line and the place where it goes.
5. **Write the first lines of the project's Current State in `memory/CURRENT_STATE.md`, and record the open owner steps there.** [reference/finishing-memory-setup.md](reference/finishing-memory-setup.md) gives the values for each heading.
6. **Run this choice's checks.** [reference/finishing-memory-setup.md](reference/finishing-memory-setup.md), "Check the local choice", gives them.

When a step does not work as expected, open [reference/local-memory-known-problems.md](reference/local-memory-known-problems.md).
