# Finding

Answer from what's recorded, name the source, and never guess.

## Where to look, in order

1. The fact's home, per the root `AGENTS.md`, "Where information goes": `DECISIONS.md`, the glossary, `PROJECT.md`, `sources/INDEX.md`.
2. Memory records on the subject, then those linked to the relevant work item. Match IDs whole: WI-031 is not WI-0310.
3. The work item itself, through `managing-work-items`.
4. Current State, for what's happening now only.

Before saying nothing is recorded, search the work items and memory too.

## "What happened" questions

For a date range, read the event records and Runs tables, the Recent History of work items and project tasks that changed, sources filed in the range, `git log` for those dates, and dated Current State lines. Answer in date order.

## Trusting what you find

- Replaced: answer from the replacement.
- Retired: history only, unless the owner asks.
- Past its check-by date: say so, and check it before acting.
- Unchecked claims and lessons are not facts. Label them when you mention them.
- Verify claims about things that change (vendors, roles, processes) before acting on them.
