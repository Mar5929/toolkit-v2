# Update a system document

Use this file when an approved fact about the system changes: a rule, a term, an integration, or a diagram. This project keeps that documentation in its Notion Project Wiki. The librarian files it: finalized product documentation goes to Product Wiki, and established terms go to Terminology Glossary.

1. Search Project Wiki and the pending captures in Wiki Inbox for the subject with `managing-project-memory`. Read the record that covers it, with its status, dates, and replacement links.
2. Capture the change in Wiki Inbox with `managing-project-memory`. Include what changes, its source, the approval evidence, and the work items it affects. A working design stays in its work item until the owner approves it.
3. Read the capture back, and give the verified capture link to the skill that asked for this step. That skill writes the link in each work item that needs it.

Use `managing-project-memory` for capture authorization and verification.
