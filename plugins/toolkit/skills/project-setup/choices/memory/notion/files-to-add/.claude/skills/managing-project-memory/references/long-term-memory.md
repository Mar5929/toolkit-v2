# Finding Long-Term Memory

Long-Term Memory is a Project Wiki navigation page containing Projects, Topics, Memories, Entities and Facts collections. Read the configured page and data source identifiers in `PROJECT.md`. Projects identifies the local memory project; Memories holds durable subject records; Topics groups related subjects; Entities identifies named things; Facts holds dated statements with validity and source links.

Query relevant collections by subject, aliases, Synopsis, Keywords and linked project or work item. Follow relations and sources as needed. Read matching records' bodies and fields. Search owner-authored records even when Record Key is missing. Use `using-notion-cli` for schema inspection, complete pagination and page reads.

Prefer accepted, current evidence and follow supersession links. Proposed, informational and inferred content retains its uncertainty; deprecated, rejected and superseded records supply history. Check Review By, validity dates and sources before relying on changeable claims. Capture additions or corrections in Wiki Inbox.

Durable context qualifies only when it is project-specific, matters enough that losing it would cost a later session understanding, comes from the owner or work with the owner, and is not already owned by another record. Product documentation belongs in Product Wiki; terminology belongs in Terminology Glossary. Link those homes rather than duplicating them.
