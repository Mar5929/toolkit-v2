# Reading Current state

Current state is the Project Wiki page for working context across sessions. Read its configured page ID in `PROJECT.md`, then read the whole page and its relevant links. Its sections are Start here, Active workstreams, Working context, Coordination ownership, Blockers and pending decisions, Resume and handoff, and Keeping memory current. Preserve the project's actual headings if customized.

The tracker owns work status, approvals and next actions. Current state is a derived snapshot. Check its last update and relevant pending Wiki Inbox captures against current work before relying on it. Use `managing-work-items` to read active work and `maintaining-notion-wiki` for an on-demand refresh. Capture changes instead of editing the snapshot directly.
