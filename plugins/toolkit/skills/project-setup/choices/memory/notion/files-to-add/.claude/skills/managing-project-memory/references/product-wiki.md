# Finding Product Wiki

Product Wiki owns finalized product documentation and its decisions and rationale. Read its configured database and data source IDs in `PROJECT.md`. Query Name, Summary, System area and relevant Category; read matching bodies, Source links and Related documentation. Use `using-notion-cli` for live fields and complete query pagination.

Read Documentation status separately from Implementation status. Approved documentation can describe Planned or Partially implemented work; Live requires implementation evidence. Draft, In review and Needs review are not finalized approval. Deprecated and Retired records supply history. Check Approved by, Approved on, Last reviewed and linked evidence before relying on a claim.

Active requirements and working architecture stay in the work item's Solution Design. Capture finalized changes with existing approvals and delivery evidence in Wiki Inbox. Later changes update the relevant wiki document through another work item; do not create a duplicate local decision ledger or product specification.
