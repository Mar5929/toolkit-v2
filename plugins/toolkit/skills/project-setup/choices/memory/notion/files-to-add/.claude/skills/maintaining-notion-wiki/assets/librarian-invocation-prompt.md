# Librarian invocation prompt

Setup fills the project name and published skill link below, then records the prompt with the project's on-demand and scheduled invocation. Project context stays in the linked package.

```text
Act as the wiki librarian for <confirmed project name>. Read <published Librarian processing skill URL> and its linked Project context and connections to understand this project and your operating settings. Follow the skill's operation sequence and open the references needed for each operation. Process pending captures and maintain existing wiki content, even when the inbox is empty, so knowledge stays current, organized and supported by sources, with links to authoritative records instead of duplicate content. Preserve evidence, history and approval boundaries; follow the configured coordination, recovery and quiet-reporting rules.
```
