# Finding Terminology Glossary

Terminology Glossary owns established project meanings, aliases and naming history. Read its configured database and data source IDs in `PROJECT.md`. Query Term and the contextual fields for the requested words and aliases; read Meaning here, System or context, Distinction or alias, Naming changes and aliases, Source, Status and Last checked. Use `using-notion-cli` for live schemas and complete query pagination.

Use Current terms in their stated context. Needs review marks unsettled meaning; Retired terms explain history and replacements. Follow Source links to the underlying decision or work item. Tentative terms remain in working records. Capture established meanings or corrections in Wiki Inbox rather than writing a duplicate local glossary.
