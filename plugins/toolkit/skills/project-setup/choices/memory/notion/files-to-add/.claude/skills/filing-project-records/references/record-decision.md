# Record a decision

Use this file to record a decision or an open question that more than one work item needs, so that later work on any work item finds it. This project keeps shared decisions in its Notion Project Wiki. A shared open question stays in each affected work item, with a link to the others, until it is decided; record it there with `managing-work-items`, and capture nothing. The librarian, the skill `maintaining-notion-wiki`, files decisions: product decisions go to Product Wiki, and other lasting decisions go to Long-Term Memory.

The steps below apply to a decision. A sourced answer counts as decided only when its speaker, documented authority, date, and unambiguous decision are verified. Keep the source passage or timestamp. A tentative statement or an interpretation stays an open question.

1. Search Project Wiki and the pending captures in Wiki Inbox for the subject with `managing-project-memory`. When a record already says the same, capture nothing new; link the existing record instead.
2. Capture the verified decision in Wiki Inbox with `managing-project-memory`. Include its source, its date, who decided it, the existing approval evidence, and the work items it affects.
3. Read the capture back, and give the verified capture link to the skill that asked for this step. That skill writes the link in each work item that needs it.
4. When the owner corrects or withdraws a decision, capture the correction the same way, and name the record it replaces.

Use `managing-project-memory` for capture authorization and verification. Active questions and approvals for one work item stay in that work item, with `managing-work-items`.
