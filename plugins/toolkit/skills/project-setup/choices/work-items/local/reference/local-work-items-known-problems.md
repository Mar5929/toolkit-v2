# Known problems with local work items

This file holds what is known to go wrong when work items in local files are set up. Open it when a step of [local-work-items-setup.md](../local-work-items-setup.md) does not work as expected. Each line names a problem, and what to do.

- **The project already has a folder named `work-items/` with files of its own.** Ask the owner before you add a file there. [reference/existing-project.md](../../../../reference/existing-project.md), "Known problems", says what to offer.
