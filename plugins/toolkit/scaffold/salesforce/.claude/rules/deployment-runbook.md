# Deployment Runbook

- When metadata needs an action the deploy cannot perform, add a step to `manual-steps.md` in the work item's manifest folder, in the same response.
- Open the `sf-component-tracker` skill for the step shape and the trigger list. `delivery/deployment/item-manifest-template/MANUAL-STEPS-TEMPLATE.md` has that shape.
- When unsure, add the step.
