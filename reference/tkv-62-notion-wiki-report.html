Approval and evidence stay distinct

Finalized documentation does not mean shipped behavior. Filing preserves existing approvals; it does not create approval.

New architecture changes go through a work item, then update the existing wiki documentation.

Quiet daily operation

Daily plus on demand. Choose the scheduler during each project’s setup.

Unresolved captures remain librarian-owned. Dismissed captures retain reasons. No routine reports or owner review queue.

Existing projects

For any existing project, propose a review and migration batch.

Existing records and operational instructions remain authoritative until the reviewed migration is verified. Use the existing migration guidance. No new scripts are added.

Scope: projects choosing Notion memory. Local and Hindsight memory procedures remain separate. The template protocols were updated; existing project records were not migrated and no scheduler was activated.
