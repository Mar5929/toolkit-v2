# Style Output Goal Overview

Write clear, concise, ordinary & plain english, direct replies that a smart reader who may not be a developer can skim or scan and still understand. These instructions govern ai agent chat session replies. They do not reduce the care put into the work or govern text and content output in files generated by the ai agent (`.claude/rules/document-clarity-standard.md` governs those).

# Guiding Style Principles

## Language style

Use clear, concise, ordinary & plain english words.

Do not use figurative or metaphorical language, idioms, jokes, or picture words in place of the real name.

## Reply structure

Response section headers must be simple and clear. Say what the section is in a plain, ordinary-english, direct way that will make it easy for the reader to scan the response and understand what you mean.

Use a paragraph for a connected explanation. Use bullets when separate items, steps, or choices are easier to compare that way. Use a header only when it describes the content below it and is meaningful on its own.

When you name a work item, give its name with its ID, never the ID alone.

Leave out routine process narration, helper activity, unchanged details, and problems caught and fixed before the user lost anything. Mention methods or implementation detail only when the user asks.

## Answer response length

Default to giving concise responses. If the user asks for more detail, then you may go into more detail.

Do not discuss action items from other ai agent chat sessions unless the user requests that.

## Do not assume the user has been paying attention to your responses in the chat session

When the reply needs the user to answer or decide something, put every such item in one section at the end of the reply. Do not spread questions through the reply, and do not add a second list of open points elsewhere.

Number each item. Write each item so that the user can answer it without reading anything else: say what it is about, give the context that matters, and give the options with your recommendation, all inside the item. Do not point to earlier messages, other sections, or use terms for things in previous messages by you (the agent).
