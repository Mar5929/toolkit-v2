# Project status report

Use this when the owner asks where the project stands, what waits on the owner, or what comes next, such as "where are we". The report is done when the owner can see what is open, who owes each part, which dates matter, and which work item to start next.

- Read the open work items and project tasks from the work tracker, as `work-tracker.md` says.
- Read the project's current state as `AGENTS.md`, "Project memory", says.
- Read outstanding shared questions where `AGENTS.md`, "Where information goes", keeps them.
- Report applicable dated commitments from those records, and say when a date has passed.
- Report each open project task with who owes it, and unsaved work in the worktree of each work item in progress.
- Name the next work item to start: started work first, then the earliest project phase that is not Done, then the highest-priority work item in Backlog.
