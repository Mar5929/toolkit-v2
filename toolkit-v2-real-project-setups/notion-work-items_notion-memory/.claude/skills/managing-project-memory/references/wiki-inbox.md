# Wiki Inbox

Wiki Inbox holds submissions for the librarian, not finished knowledge. Its fields and status options are in `maintaining-notion-wiki/references/wiki-schemas.md`.

## Capturing a change

- Search matching captures and destination records first.
- If an unclaimed capture with status New or Needs review covers the same change, add your evidence to it, keeping its contributor and sources. If the matching capture is Processing or Filed, create a linked follow-up instead.
- Otherwise create a row with Name, Capture, Source, and Contributor, and Processing status New. Put source links or IDs, dates, work item links, uncertainty, correction targets, and approval evidence in Capture or Source. You can suggest Destination areas; the librarian decides.
- The librarian owns Processing notes, outcomes, and Filed links.
- If a create may have failed, search Wiki Inbox for a matching capture before retrying.

## Reading recent information

Query New, Processing, and Needs review rows on the subject, with their Capture, Source, and page bodies. Filed rows link to their destinations in Filed links; Dismissed rows give the reason in Processing notes. Needs review means unfinished librarian work, not a task for the owner.
