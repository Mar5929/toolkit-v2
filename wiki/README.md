# Toolkit wiki

The product pages define what Toolkit V2 should do. The research records show how Mike uses projects and what the toolkit needs to support.

## Real project requests and examples

Start with [How the owner works with agents](archive/how-the-owner-works-with-agents.md). It inventories Mike's requests across 17 Davis sessions and 43 Dragonfly sessions reviewed through October 7, 2026. It includes his actual messages, recurring workflows, things he had to repeat, delays and where project files ended up.
