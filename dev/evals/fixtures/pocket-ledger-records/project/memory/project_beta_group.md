# Beta group

## Size, and where the testers live

**Remember:** The beta group has 12 testers. All 12 live in the United States. This was true on 2026-09-29.

**Why:** The number of testers is the number of TestFlight invitations that Mike sends. Where the testers live decides which currencies the first beta needs.

**How to apply:** Use this number when Mike asks how big the beta is or how many invitations to send. Whether a person outside the United States may join is an open decision, DEC-002.
