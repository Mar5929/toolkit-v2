### Solution options and considerations

These are possibilities to evaluate, **not approved requirements or design decisions**.

| Option | iOS versions | Effort to use | How the chart looks |
|---|---|---|---|
| Swift Charts (built into iOS) | iOS 16 and newer | Low: a few lines for each chart | Matches the look of the rest of the system |
| An open-source charting library | Older iOS versions too | Medium: add the library and learn its settings | Many styles, and some look dated |
| Drawing the chart ourselves | Any iOS version | High: every bar, label, and tap is ours to build | Exactly what we design |

Recommended: Swift Charts. The app supports iOS 17 and newer (DEC-001), Swift Charts is built in so nothing extra is installed, and it takes the least work.
