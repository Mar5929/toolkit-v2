## Project brief

- **For:** People new to Node who cloned this repository.
- **What it does:** `quote.js` picks one random quote from its `quotes` list and prints it to the terminal.
- **Run it:** With Node.js installed, run `node quote.js` from the repository root.
- **Add a quote:** In `quote.js`, add another quoted string as an entry in the `quotes` list.

This tiny Node.js project prints one random quote when you run `quote.js`.

## Purpose

The script chooses a quote from the list in `quote.js` and prints it to the terminal.

## Start here

1. Use a local installation of Node.js.
2. From this repository's root, run `node quote.js`.
3. Read the printed quote. There are no tests yet.
