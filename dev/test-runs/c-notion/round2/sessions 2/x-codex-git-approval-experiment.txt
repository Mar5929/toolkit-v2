Result: with approval policy 'never' the rule rejects git add ('approval required by policy, but AskForApproval is set to Never').
With --approve-for-me the matched prompt rule let git add run, but inside the sandbox: 'fatal: Unable to create .../.git/index.lock: Operation not permitted'.
Only an explicit escalation request (sandbox_permissions require_escalated) ran git add outside the sandbox; git status then showed 'A  b.txt'.
