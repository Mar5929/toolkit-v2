# Toolkit V2 sample run c (safe to delete)

This project contains a small Node.js script that prints a random quote.

## Project brief

- This project is for people new to Node who have cloned the repository.
- `quote.js` prints one random quote from its list.
- Run it with `node quote.js`.
- To add a quote, add another quoted line followed by a comma inside the `quotes` array in `quote.js`.

## Purpose

Run `quote.js` locally to print one of the quotes in its list. Mike Rihm owns the project.

## Start here

1. Open this repository on a computer with Node.js installed.
2. Use the project folder; the script has no separate environment.
3. Run `node quote.js`.
