# Coding preferences

**Remember:** The owner prefers error messages that tell him how to fix the problem. For tests, use Node’s built-in node:test runner and no npm packages.

**Why:** Not stated by the owner.

**How to apply:** When writing an error message, include a concrete corrective action. When adding tests, use node:test and avoid npm test dependencies.
