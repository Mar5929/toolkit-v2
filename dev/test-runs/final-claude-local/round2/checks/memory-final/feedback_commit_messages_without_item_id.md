# Commit messages without the work item ID

**Remember:** Commit messages leave out the work item ID (for example WI-001). They just say what changed.

**Why:** Not stated by the owner.

**How to apply:** When writing any commit message in this project, describe the change only. Do not put a work item ID in the subject or body. Branch names and pull request text are not covered by this preference.

**Evidence and limits:** Mike Rihm, in chat, 2026-09-28. Applies to commit messages.
