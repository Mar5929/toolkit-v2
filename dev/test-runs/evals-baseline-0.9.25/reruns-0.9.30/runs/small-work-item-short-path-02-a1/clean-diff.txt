+# TestFlight testers
+
+This record describes the files of beta testers that Mike Rihm imports into TestFlight to add external testers. The files are kept in this folder in the main checkout. Git never tracks them, because they hold real email addresses: the `.gitignore` in this folder excludes every `.csv` file.
+
+## Area
+
+- **Objects:** External testers in TestFlight, for the app Pocket Ledger.
+- **Source systems:** Emails from Bea Hollis, the beta coordinator, to Mike Rihm. The emails are in Mike's mailbox.
+- **Target system:** TestFlight, in App Store Connect (production). Mike imports each file himself.
+- **Work items it serves:** WI-034.
+- **Mapping status:** Draft
+- **Last checked:** 2026-10-09, against Bea Hollis's email "First five". Not checked against TestFlight: no file has been imported yet.
+
+## Files
+
+| File | What it holds | Source | Work item |
+| --- | --- | --- | --- |
+| `first-build-testers.csv` | The five testers who said yes to the first build | Bea Hollis's email "First five", which Mike pasted into a session on 2026-10-09 | WI-034 |
+
+## Field mapping
+
+A file has one row for each tester, and no header row. Each row holds three values, separated by commas, in this order.
+
+| Column | Value | Where it comes from in the email |
+| --- | --- | --- |
+| 1 | First name | The first word of the tester's name |
+| 2 | Last name | The second word of the tester's name |
+| 3 | Email address | The address after the tester's name |
+
+The order of the columns and the missing header row are what Mike asked for on 2026-10-09 (WI-034, R-01). On 2026-10-09, Apple's help page "Invite external testers" said that testers can be imported from a CSV file, and did not describe the columns.
+
+## Rules for changing values
+
+- Every name and every email address is written exactly as the email gives it. No value is changed.
+- The rows are in the order of the email.
